# 판정 방법

## 1. 측정량
InSAR는 첫 촬영일부터의 시선방향(LOS) 변위를 측정합니다. 수직 변위는 LOS / cos(입사각)으로 환산합니다 (수평 성분 무시 가정; 상승·하강 궤도가 함께 있으면 두 결과를 비교해 일치 여부를 표시).
교량 변위는 **교량 주변 지반(축에서 30–300 m) 대비**로 계산합니다. 지역 전체 침하·기준점 위치 영향이 빠지고 교량 자체의 거동만 남습니다.

## 2. 자료 품질
- 수직 기선 |B⊥| > 200 m 날짜 제외 (정합 전에 제외)
- 기준점: 교량에서 100 m 이상 떨어진 안정 지반 PS 묶음(50 m 이내), 시간 결맞음 ≥ 0.95. 없으면 0.92 → 0.90 → 0.85 → 0.80으로 낮추고 결과에 표시
- 시기별 기준점 결맞음 |평균 exp(jφ)| ≥ 기준값, 미달 날짜 제외
- 열 신축 보정: 노드별 y = a + v·t + kT·(T − T̄) 적합, 촬영 시각 기온(ERA5)으로 kT·ΔT 제거

## 3. 허용변위 대비 판정
| 항목 | 측정 | 허용값 |
|---|---|---|
| 누적 수직변위 | 지점부(교대·교각 추정 위치) 변위속도 × 관측기간 | 총침하 25 mm (inframon life.limits 와 통일) |
| 부등변위 | 인접 지점 변위 차 / 경간 | 각변위 1/500 (모든 형식, inframon life.limits 와 통일) |

- 주변 지반 변위속도의 산포(2 × MAD)와 추세 표준오차 2배 중 큰 값을 넘지 않는 변위는 0으로 둡니다 (오차 범위).
- 비율 = 측정 / 허용. 종별 기준(관심/주의/경고): 1종 0.3/0.5/0.7, 2종 0.4/0.6/0.8, 3종·기타 0.5/0.7/0.9
- 현재 속도로 10년 뒤 예측 비율은 등급을 한 단계까지만 올립니다.
- 교량 위 PS 5점 미만 또는 노드 확보율 25 % 미만, 교대부 대체 판정은 주의 이상이어도 "확인 필요"로 분리합니다.

## 4. 점이 부족한 교량
1. 산악지 적응형 PS 후보 선정 (날짜별 진폭 보정, 3–11월 영상으로 진폭 분산, 표준 임계 0.42에서 후보 1,500개 미만이면 상위 12 %, 최대 0.70)
2. Capon(MVDR)·APES(López-Dekker & Mallorquí 2010) 2배 재초점 → StaMPS, 1차 결과와 지반 점 쌍으로 기준 통일
3. DS 위상연결(통계적 동질 화소 + EMI) → StaMPS
4. 노드별 우선순위 APES PS > Capon PS > 1차 PS > DS
5. 그래도 교량 위 점이 없으면 양 끝 교대부(10–200 m) 지반 거동으로 대체 판정 (참고)
